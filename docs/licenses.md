# Registro de licenças

Inventário local: [license-registry.json](license-registry.json), gerado por `.venv\Scripts\python.exe scripts/licenses.py`.
Inclui nome, versão, licença, URL quando fornecida pelo pacote, uso comercial, redistribuição,
pesos, atribuição e restrições. Campos sem confirmação permanecem como revisão necessária.

Fontes oficiais consultadas:

- [React MIT](https://github.com/facebook/react/blob/main/LICENSE)
- [Three.js MIT](https://github.com/mrdoob/three.js/blob/dev/LICENSE)
- [Vite MIT](https://github.com/vitejs/vite/blob/main/LICENSE)
- [FastAPI MIT](https://github.com/fastapi/fastapi/blob/master/LICENSE)
- [Uvicorn BSD](https://github.com/encode/uvicorn/blob/main/LICENSE.md)
- [psutil BSD](https://github.com/giampaolo/psutil/blob/master/LICENSE)

MIT/BSD permitem distribuição e uso comercial sob suas condições: preservar os textos e avisos de copyright;
BSD-3-Clause também proíbe usar nomes de autores para endosso sem permissão.
TypeScript/Apache-2.0 exige preservação de avisos aplicáveis e documentação de alterações.
Certifi (dependência de teste) usa MPL-2.0: redistribuição de arquivos cobertos/modificados exige observar copyleft por arquivo.
Não redistribuímos pesos de IA. Hunyuan3D continua bloqueado até revisão de versão/licença/contexto de uso.
Não foi escolhida uma licença para o código autoral FORGE em nome do proprietário.
Os metadados não substituem os textos de licença incluídos em cada pacote; preservá-los no empacotamento.
